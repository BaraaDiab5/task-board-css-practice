# Simple Kanban Board UI

A static task-board interface built during my early days of learning web layout techniques using pure HTML and CSS.

### 📌 About the Project
* **Core Focus:** Practicing fundamental CSS styling (Flexbox/Grid layout, cards, soft shadows, and spacing).
* **Tech Stack:** Pure HTML5 & CSS3.
* **Note:** This was an early experimental build created purely for layout experimentation (non-responsive desktop view), kept here as a milestone in my frontend learning journey.
